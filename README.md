# WESTWOOD Patch Copy

WESTWOOD Instruments (westwoodinstruments.com) のパッチ名を `製品名 - パッチ名` の形式でクリップボードにコピーするローカルツール。Studio One 等のトラック名として貼り付けることを想定。

- 完全ローカル動作、外部通信なし
- 表示状態は localStorage に保存
- 制作手順・注意点は [PLAYBOOK.md](https://github.com/fdorceo-design/SA_Patch_Copy/blob/main/PLAYBOOK.md) (SA Patch Copy) を参照

GitHub Pages: https://fdorceo-design.github.io/WESTWOOD_Patch_Copy/
